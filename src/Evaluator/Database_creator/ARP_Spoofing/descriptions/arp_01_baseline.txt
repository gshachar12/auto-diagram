Before any attack activity occurs, the local hosts on this network -- the
gateway, kali, and the victim machine -- each perform normal ARP requests
to discover one another's MAC addresses, each using its own genuine
hardware address. At one point the victim host replies legitimately to
an earlier ARP request from kali, using its own real MAC address. Kali
then sends an unsolicited ARP reply to the victim, falsely claiming to
own the gateway's IP address, using kali's own real MAC address as the
claimed owner of that address. As a result of the victim's now-poisoned
ARP table, the victim's DNS queries -- addressed at the IP layer to the
real gateway -- end up being delivered at the link layer to kali
instead. Kali forwards this intercepted traffic on to its real
destination, including HTTPS sessions to reddit.com's infrastructure,
which lets kali observe metadata such as the destination's TLS Server
Name Indication and certificate details, without being able to read the
encrypted contents themselves.
