The attack details a security incident transitioning through initial discovery, active compromise, and subsequent traffic sniffing. The initial baseline phase reveals local hosts interacting within default domains on a private IP space, during which active network nodes are identified and mapped by hardware MAC address to logical IP address. Within this segment, an offensive framework host named "kali" exposes its presence via network broadcasts. The attack transitions into ARP spoofing and cache poisoning as the Kali host broadcasts a continuous stream of unsolicited ARP reply packets across the local network without prior requests. These forged packets alter the target hosts' ARP tables by mapping the default gateway's IP address and the victim's IP address directly to the attacker's MAC address. As local caches update with these spoofed records, a transparent Man-in-the-Middle position is established, forcing both inbound and outbound victim traffic through the attacker's interface, where IP forwarding routes the packets to their true destinations to avoid detection. Positioned as an interception proxy, the attacker captures plain-text DNS queries on UDP Port 53, monitoring lookups for hosts such as debian.pool.ntp.org along with general web requests. This monitoring extends to HTTP and HTTPS web interactions, directly exposing API endpoints and web traffic for reddit.com and gql.reddit.com. Furthermore, TLS handshakes reveal clear-text Server Name Indication (SNI) fields inside Client Hello packets and reflect DigiCert-issued digital certificates for the target domains. Overall, key indicators of compromise extracted from the capture include the "kali" hostname, target domains reddit.com, gql.reddit.com, and debian.pool.ntp.org, DigiCert-issued digital certificates, and a distinct attack pattern marked by continuous, unsolicited ARP Reply (Opcode 2) frames mapping a single MAC address simultaneously to multiple IP addresses.
