Ransomware Infection Chain — Baseline (Accurate)
====================================================

Step 1 — Lure delivery and redirect
  The victim host requests a resource from a remote web server. The
  server responds with an HTTP redirect leading directly to a JavaScript
  downloader hosted on the same infrastructure.

Step 2 — Downloader execution
  The victim host fetches the JavaScript file. This script's role is to
  retrieve and launch the actual malicious payload.

Step 3 — Payload retrieval
  The victim host fetches an executable file from a separate, disposable
  -looking domain. This is the ransomware payload itself.

Step 4 — Local network scanning
  Shortly after the payload is retrieved, the infected host scans a large
  range of external IP addresses on a single, non-standard UDP port.

Step 5 — Command-and-control check-in
  Later in the session, the infected host contacts a command-and-control
  server, using a domain with a random-looking subdomain under an
  uncommon top-level domain.

Step 6 — Encryption and ransom demand
  The payload is presumed to encrypt local files consistent with typical
  ransomware behavior of this style, though this cannot be confirmed from
  network traffic alone.
